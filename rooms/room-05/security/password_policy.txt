  1. RÈGLES OBLIGATOIRES
  ════════════════════════════════════════════════════════════════

  Tout mot de passe企業 doit respecter les critères suivants :

    ✓ Minimum 12 caractères
    ✓ Au moins 1 lettre majuscule (A–Z)
    ✓ Au moins 1 lettre minuscule (a–z)
    ✓ Au moins 1 chiffre (0–9)
    ✓ Au moins 1 caractère spécial : ! @ # $ % ^ & *

  2. STRUCTURES RECOMMANDÉES
  ════════════════════════════════════════════════════════════════

  Pour faciliter la mémorisation tout en respectant les règles,
  les structures suivantes sont recommandées :

    📌 Pattern A :  Prénom + Ville + Année + Symbole
       Exemple :    Alice + Paris + 2019 + !

    📌 Pattern B :  Lieu + Année + Symbole
       Exemple :    London + 2020 + @

    📌 Pattern C :  Passion + Date + Symbole
       Exemple :    Escalade + 2018 + #

  ⚠️  IMPORTANT :
      Le "Lieu" doit être un endroit SIGNIFICATIF pour vous
      (ville de naissance, lieu de vacances, lieu de travail…)
      L'année doit être LIÉE à ce lieu.

  3. RÈGLES SUPPLÉMENTAIRES
  ════════════════════════════════════════════════════════════════

    ✗ Ne pas réutiliser un mot de passe parmi les 5 derniers
    ✗ Ne pas utiliser votre prénom seul comme mot de passe
    ✗ Ne pas utiliser "password", "123456", ou des suites
    ✗ Ne pas écrire votre mot de passe sur papier ou dans un fichier
      non chiffré

  4. RENOUVELLEMENT
  ════════════════════════════════════════════════════════════════

    • Durée de validité : 90 jours
    • Renouvellement obligatoire avant expiration
    • En cas d'oubli : contactez le support IT

  5. STOCKAGE & HASHING
  ════════════════════════════════════════════════════════════════

    Les mots de passe sont stockés sous forme de hash SHA-512.
    Algorithme : $6$ (crypt SHA-512)
    Rounds : 5000
