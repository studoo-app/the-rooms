Bienvenue dans le système de Michel !

Michel, 70 ans, ancien agent de sécurité, n'ouvre sa porte qu'à ceux
qui savent se présenter correctement. Le fichier contenant le code de
son archive est gardé par Ginette sur une machine que l'on ne peut
pas rejoindre comme ça.

Votre mission :
  Trouvez comment accéder à la machine de Ginette et récupérez-y le
  code de déverrouillage de l'archive de Michel. Une fois l'archive
  ouverte, vous y trouverez ce dont vous avez besoin pour continuer
  votre aventure.
